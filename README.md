# receptionist-core

A modular digital receptionist engine for handling intake, scheduling, and client communication across industries. Designed to integrate with systems like CareClerk and other CRM platforms.

## 🚀 Purpose
Receptionist Core is built to automate front desk operations such as:
- Capturing client/patient intake
- Scheduling appointments
- Sending confirmations and follow-ups
- Routing requests to the appropriate system or staff

## 🧩 Core Features (MVP)
- Intake API (form + chat support)
- Scheduling engine (auto + assisted)
- Basic notification system
- Request tracking and status management

## 🔌 Integrations (Planned)
- CareClerk (healthcare workflow system)
- External calendars (Google Calendar, Calendly)
- SMS and email providers

## 🏗️ Architecture
This project is designed as a standalone service that can plug into multiple systems across industries (healthcare, contractor, legal, etc.).
